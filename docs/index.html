CardTabs
GitHub

Vanilla JavaScript + CSS

Simple tabs without the weight.

CardTabs is a tiny, dependency-free tab component for quick, clean interfaces. It keeps the core idea simple: a container, tab labels, and panel content.

Get started Download

Getting started

Install in seconds

<link rel="stylesheet" href="path/to/jquery.cardtabs.css">
<script src="path/to/jquery.cardtabs.js" defer></script>
<div class="container">
  <div data-tab="Overview">...</div>
  <div data-tab="Details">...</div>
</div>
document.querySelectorAll('.container').forEach((el) => el.cardTabs());
// or
cardTabs('.container');

Usage

Keep your markup simple

HTML

<div class="example-tabs">
  <div data-tab="Tab one">First tab content</div>
  <div data-tab="Tab two">Second tab content</div>
  <div data-tab="Tab three">Third tab content</div>
</div>

JavaScript

const tabs = document.querySelector('.example-tabs');
tabs.cardTabs();

// or
cardTabs('.example-tabs', { theme: 'inset' });

Customization

Make it your own

.card-tabs-bar.your-theme {
  /* bar styles */
}

.card-tabs-bar.your-theme .card-tabs-tab {
  /* tab button styles */
}

.card-tabs-bar.your-theme .card-tabs-tab.active {
  /* active state */
}

.card-tabs-stack.your-theme .card-tabs-panel {
  /* panel styles */
}
